# Branding

This folder holds ForgeOS **brand assets**: logo, colour palette, typography and brand guidelines.

Brand assets are used in the README, onboarding material and any external ForgeOS documentation.

---

# Current Contents

At v1.0.0 this folder is **empty**. No ForgeOS logo, palette or typography assets have been produced yet.

When brand assets are added, this README must be updated to index them.

---

# Conventions

Inherited from `Framework/10-Assets/README.md`:

* Store editable source (e.g. `.svg`, `.ai`, `.fig`) alongside any rendered output.
* Name assets after what they are (e.g. `forgeos-logo-primary.svg`, `forgeos-palette.json`).
* Do not duplicate assets across folders.

---

# Authority

Brand assets are supporting material. They never override Framework engineering truth. Authority flows from `Framework/10-Assets/README.md`.
