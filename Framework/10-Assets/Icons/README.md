# Conventions

Inherited from `Framework/10-Assets/README.md`:

* Prefer SVG over raster so icons scale crisply.
* Name icons after what they represent (e.g. `icon-sdl-phase.svg`), not sequentially.
* Group related icons into subfolders if the set grows.
