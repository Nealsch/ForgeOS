# Documentation and Knowledge Skills

## Purpose

Documentation and Knowledge Skills define the capabilities used to create and maintain engineering knowledge.

These Skills cover technical documentation, API documentation, architecture documentation, user documentation, release notes, changelog management, markdown authoring, diagram documentation, knowledge management, decision recording and requirements traceability.
