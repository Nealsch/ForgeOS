# 03-Engineering

Skills in this category turn approved designs and requirements into working, maintainable software. Together they cover the engineering discipline from interface design, through implementation (backend, frontend, data), to the supporting practices that keep code healthy: secure coding, refactoring, review, debugging, dependency hygiene, and measurement.

**Engineering skills build what Architecture designs and Product specifies.** Design artefacts are consumed, not re-decided: API design realises integration designs, database implementation realises data models, and secure coding applies the OWASP standards at the implementation moment — verification afterwards belongs to the Security and Quality categories.

## Skills

| Skill | Responsibility |
| ----- | -------------- |
| [Forge-API-Design](Forge-API-Design/SKILL.md) | Designs consistent, consumable interfaces between system components. |
| [Forge-Backend-Development](Forge-Backend-Development/SKILL.md) | Implements server-side functionality against approved designs. |
| [Forge-Frontend-Development](Forge-Frontend-Development/SKILL.md) | Implements user-facing interfaces that realise UX and functional requirements. |
| [Forge-Database-Implementation](Forge-Database-Implementation/SKILL.md) | Implements persistence — schemas, migrations, and data access — from approved data models. |
| [Forge-Secure-Coding](Forge-Secure-Coding/SKILL.md) | Applies the OWASP Proactive Controls, Cheat Sheets, and ASVS to day-to-day implementation decisions. |
| [Forge-Refactoring](Forge-Refactoring/SKILL.md) | Improves internal structure and maintainability without changing observable behaviour. |
| [Forge-Code-Review](Forge-Code-Review/SKILL.md) | Reviews changes for correctness, standards conformance, and maintainability before integration. |
| [Forge-Debugging](Forge-Debugging/SKILL.md) | Diagnoses and isolates defects and failures in a disciplined, evidence-driven way. |
| [Forge-Dependency-Analysis](Forge-Dependency-Analysis/SKILL.md) | Analyses third-party dependencies for risk, currency, and licence implications. |
| [Forge-Repository-Metrics](Forge-Repository-Metrics/SKILL.md) | Interprets repository metrics into engineering-grade health indicators. |

## Relationship To The SDLC

Engineering skills are primary for the **Develop** phase, and contribute to **Design** (feasibility input), **Verify** (fixes for defects found in testing), and **Operate** (debugging production issues, dependency maintenance).
