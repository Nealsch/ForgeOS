# Project Definition

## Purpose

Document the overall project purpose, scope, objectives, and success criteria to create a shared understanding.

## When Used

Use this template during project initiation, onboarding, or whenever project context needs to be aligned across stakeholders.

## Produced By

Forge-Knowledge-Management or equivalent project definition activity.

## Consumed By

* Product owners
* Architects
* Engineers
* QA
* Stakeholders

## Template

### Project Purpose

Describe why the project exists and what it aims to achieve.

### Objectives

List the high-level objectives the project must deliver.

### Scope

Define what is included in scope and what is explicitly excluded.

### Success Criteria

Define the conditions that will determine whether the project is successful.

### Key Stakeholders

List the primary stakeholders and their roles.

### Constraints

Document known constraints such as budget, timeline, technology, or regulatory requirements.

### Assumptions

Capture assumptions that affect the project context or execution.

### Risks

List the major risks and mitigation considerations.

## Completion Criteria

* Project purpose and objectives are clearly documented.
* Scope boundaries are defined.
* Success criteria are recorded.
* Stakeholders, constraints, assumptions, and risks are captured.
