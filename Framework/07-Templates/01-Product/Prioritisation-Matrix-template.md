# Prioritisation Matrix

## Purpose

Provide a structured way to compare work items and make prioritisation decisions based on value, effort, risk, and dependencies.

## When Used

Use this template when selecting or ordering work items for delivery planning, product roadmapping, or release planning.

## Produced By

Forge-Prioritisation or equivalent prioritisation activity.

## Consumed By

* Product owners
* Delivery planning
* Engineering teams
* QA

## Template

### Work Item Summary

List the candidate work items with a short description for each.

### Prioritisation Criteria

Define the criteria used to compare work items, such as:

* Business value
* User impact
* Effort or cost
* Risk
* Dependencies
* Strategic alignment

### Prioritisation Matrix

Create a table with columns for each criteria and a score or ranking for each item.

| Work Item | Description | Value | Effort | Risk | Dependencies | Priority | Notes |
| --------- | ----------- | ----- | ------ | ---- | ------------ | -------- | ----- |

### Recommendation

Summarise the recommended ordering and the rationale.

### Trade-offs and Assumptions

Document the assumptions made and the trade-offs considered during prioritisation.

## Completion Criteria

* Candidate work items are listed clearly.
* Prioritisation criteria are defined and applied consistently.
* The recommended priority order is explained.
* Dependencies, risks, and assumptions are recorded.
