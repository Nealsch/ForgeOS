# User Story

## Purpose

Capture a discrete user need as a structured story that can guide design, implementation, and validation.

## When Used

Use this template when requirements have been analysed and a user-focused slice of work is ready for development.

## Produced By

Forge-User-Story-Definition or equivalent user story creation activity.

## Consumed By

* Product owners
* Engineers
* QA
* UX designers

## Template

### User Story

As a [user role], I want [goal] so that [benefit].

### Acceptance Context

Describe how success should be observed.

### Supporting Requirements

List related requirements, constraints, or dependencies.

### Dependencies

Capture any external dependencies or prerequisites.

### Related Decisions

Link to relevant decisions, assumptions, or architecture notes.

## Completion Criteria

* The story is clear, concise, and user-focused.
* Acceptance context is defined.
* Dependencies and related requirements are identified.
* The story can be used to create implementation and test tasks.
