# Test Plan

## Purpose

Document the detailed approach for executing tests against a specific scope, release, or feature.

## When Used

Use this template after the test strategy is approved and the team is ready to organise test execution.

## Produced By

Forge-Test-Planning or equivalent test planning activity.

## Consumed By

* QA teams
* Engineering teams
* Test coordinators

## Template

### Test Scope

Describe what will be tested and what is out of scope.

### Objectives

List the goals of the testing effort.

### Test Items

List the features, user stories, or components covered by this plan.

### Test Types

Identify the types of tests that will be performed, such as:

* Functional
* Integration
* Regression
* Performance
* Security
* User acceptance

### Test Cases or Scenarios

For each test case or scenario, include:

* ID
* Title
* Description
* Preconditions
* Steps
* Expected results
* Acceptance criteria

### Coverage and Traceability

Link tests back to requirements, user stories, or acceptance criteria.

### Responsibilities

Identify who is responsible for test design, execution, and verification.

### Schedule and Milestones

Document the timing for test execution, reviews, and sign-offs.

### Risks and Contingencies

Capture test risks and any contingency plans.

## Completion Criteria

* The test scope and objectives are defined.
* Test cases or scenarios are captured.
* Coverage is linked to requirements.
* Responsibilities and schedule are documented.
* Risks and contingencies are identified.
