# Release Plan

## Purpose

Document the release scope, schedule, dependencies, and readiness criteria to align delivery stakeholders.

## When Used

Use this template when planning a release, deployment, or incremental delivery milestone.

## Produced By

Release planning activity or equivalent delivery coordination.

## Consumed By

* Engineering teams
* QA
* Operations
* Product owners

## Template

### Release Summary

Describe the release objective, target audience, and key outcomes.

### Release Scope

List the features, fixes, and changes included in this release.

### Schedule

Capture target dates, milestones, and deployment windows.

### Readiness Criteria

Define the conditions required before release, such as:

* Completed testing
* Security review
* Documentation updates
* Deployment readiness

### Dependencies

Document dependencies on systems, teams, or external parties.

### Risks and Mitigations

List known risks and the actions planned to reduce them.

### Roles and Responsibilities

Identify who is responsible for release activities, approvals, and communication.

## Completion Criteria

* Release scope and objectives are clearly defined.
* Schedule and milestones are captured.
* Readiness criteria are documented.
* Dependencies and risks are recorded.
* Roles and responsibilities are assigned.
