# Release Scope

Scope approved by the **Product Owner** as the complete ForgeOS Framework baseline at the point of release. No new functionality is planned beyond v1.0.0.

The release comprises:

* `Framework/` — Workflow, Standards, Governance, Agents, Skills, Prompts, Templates, Examples, Onboarding, Assets, Collaboration Orchestration, Glossary.
* `Tooling/` — Platforms, Adapters, Capabilities.
* `ForgeOS Project/` — living project documentation (ADRs, Roadmap, Backlog, Release Notes).
