# Release Scope

Scope approved by the **Product Owner** as a backwards-compatible patch containing cleanup, referential-integrity fixes, and a new tooling-side installer. No framework capabilities were added, removed, or changed.

The release comprises:

* **Fixed** — 3 truncated skill artefacts, 1 legacy `NB-` prefix, 3 non-skill misuses of the `Forge-` prefix (9 references across 8 files), 2 truncated stub folders, 1 frontmatter typo.
* **Added** — Cline skill installer (`Tooling/01-Platforms/Cline/scripts/`); skill-graph gaps backlog (`ForgeOS Project/Backlog/skill-graph-gaps-backlog.md`).
* **Updated** — release notes index, roadmap baseline (current-state + baseline table).

Full detail is in `ForgeOS Project/Release Notes/1.0.1.md`.
