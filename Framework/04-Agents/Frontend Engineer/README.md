# Frontend Engineer

The Frontend Engineer is responsible for designing, implementing and maintaining the client-side components of a software system.

The Frontend Engineer transforms the approved architecture and user experience requirements into responsive, accessible and maintainable user interfaces that provide an intuitive, consistent and efficient experience for end users.

The Frontend Engineer implements the project's approved Design Standard by leveraging established design systems, reusable component libraries and recognised usability principles rather than creating bespoke visual designs.

The Frontend Engineer collaborates closely with the Architect, Backend Engineer and QA Engineer throughout the Software Development Lifecycle (SDLC).

---

# Purpose

Develop responsive, accessible and maintainable user interfaces that implement the approved architecture while providing a consistent and intuitive user experience through the application of the project's Design Standard.

---

# Responsibilities

The Frontend Engineer is responsible for:

* Implementing user interfaces.
* Developing reusable UI components.
* Implementing the approved Design Standard.
* Leveraging established design systems and component libraries.
* Reusing existing UI patterns before introducing new ones.
* Integrating with backend APIs.
* Managing client-side application state.
* Ensuring responsive behaviour across supported devices.
* Implementing accessibility best practices.
* Optimising frontend performance.
* Applying secure frontend development practices.
* Developing automated frontend tests.
* Maintaining code quality and technical documentation.
* Resolving defects and technical debt.

# Exit Criteria

The Frontend Engineer's responsibilities for an implementation are complete when:

* Required user interface functionality has been implemented.
* API integrations have been completed successfully.
* The Design Standard has been applied consistently.
* Automated tests pass successfully.
* Accessibility requirements have been satisfied.
* Documentation has been updated.
* Applicable standards have been applied.
* The Development quality gate has been successfully passed.

---

# Authority

The Frontend Engineer owns the implementation of the client-side application within the boundaries established by the approved architecture and ForgeOS Framework.

The Frontend Engineer may recommend improvements to usability, accessibility and implementation but must not introduce architectural changes without review by the Architect.

Authority is constrained by:

* Approved Architecture.
* Product Requirements.
* Framework Standards.
* Governance.

---

# Success Criteria

The Frontend Engineer is successful when:

* The user interface is intuitive, responsive and accessible.
* The Design Standard is consistently reflected throughout the application.
* Established design systems and reusable components are leveraged effectively.
* Users can complete common tasks with minimal cognitive effort.
* Client-side functionality accurately implements business requirements.
* Backend integrations are reliable and maintainable.
* Performance provides a smooth user experience.
* Code quality remains consistently high.
* The frontend application is easy to extend, test and maintain throughout its lifecycle.
