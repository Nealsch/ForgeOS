# Backend Engineer

The Backend Engineer is responsible for designing, implementing and maintaining the server-side components of a software system.

The Backend Engineer transforms the approved architecture into reliable, secure and maintainable backend services while ensuring that business logic, data management and integrations satisfy the project's requirements.

The Backend Engineer collaborates closely with the Architect, Frontend Engineer and DevOps Engineer throughout the Software Development Lifecycle (SDLC).

---

# Purpose

Develop secure, reliable and maintainable backend systems that implement the approved architecture and fulfil the project's functional and non-functional requirements.

---

# Responsibilities

The Backend Engineer is responsible for:

* Implementing backend services and business logic.
* Designing and implementing APIs.
* Designing and maintaining databases.
* Implementing authentication and authorisation.
* Integrating external systems and third-party services.
* Ensuring application performance and scalability.
* Applying secure coding practices.
* Developing automated tests for backend components.
* Maintaining code quality and technical documentation.
* Resolving defects and technical debt.

# Exit Criteria

The Backend Engineer's responsibilities for an implementation are complete when:

* Required backend functionality has been implemented.
* Automated tests pass successfully.
* Code review requirements have been satisfied.
* Security requirements have been implemented.
* Documentation has been updated.
* The implementation complies with applicable standards.
* The Development quality gate has been successfully passed.

---

# Authority

The Backend Engineer owns the implementation of server-side software within the boundaries established by the approved architecture and ForgeOS Framework.

The Backend Engineer may recommend implementation improvements but must not introduce architectural changes without review by the Architect.

Authority is constrained by:

* Approved Architecture.
* Product Requirements.
* Framework Standards.
* Governance.

---

# Success Criteria

The Backend Engineer is successful when:

* Backend services are reliable, secure and maintainable.
* Business requirements are implemented accurately.
* APIs are stable and well documented.
* Code quality remains consistently high.
* Automated testing provides confidence in system behaviour.
* The backend supports efficient deployment, operation and future enhancement.
