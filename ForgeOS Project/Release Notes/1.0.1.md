# ForgeOS v1.0.1

**Patch release — cleanup, referential integrity, and a new tooling capability.**

---

## Summary

v1.0.1 is a backwards-compatible **Patch** release. It contains no new framework capabilities and no breaking changes. It addresses issues found during a post-v1.0.0 codebase audit: truncated skill artefacts, a stray legacy prefix, a folder-name collision, misuse of the `Forge-` prefix by non-skill entities, and the introduction of a Cline skill installer.

All changes are classified as backwards-compatible improvements and fixes per `Framework/03-Governance/Version/README.md` §Patch.

### Added

| # | Change | Files |
