# ForgeOS v1.0.0

**Initial stable release of the ForgeOS Framework.**

---

## Summary

ForgeOS is an AI-assisted Software Development Operating System: a structured, standards-driven Software Development Lifecycle (SDLC) that enables humans and AI to collaborate using a common engineering process. It is intentionally AI-platform-agnostic.

v1.0.0 establishes the **baseline** of the framework: a complete, internally consistent knowledge base, a Tooling integration layer, and the living project documentation for ForgeOS itself.

This is the **first** release. There is no prior version, so compatibility impact is **N/A**.

---

## Scope

This release contains the complete ForgeOS Framework as it stands at the v1.0.0 baseline.

### Framework (`Framework/`)

| Layer | Contents |
| --- | --- |
| `01-Workflow` | The seven-phase SDLC (Specify, Design, Develop, Verify, Release, Operate, Improve) and phase READMEs. |
| `02-Standards` | Framework, Architecture, Coding, Documentation, Security (incl. OWASP application guides), Testing, Deployment, Design. The `09-External-Industry` category is established as the home for referenced third-party industry standards. |
| `03-Governance` | Release process, change management, compatibility policy, and versioning scheme. |
| `04-Agents` | Specialist engineering roles: Architect, Backend Engineer, Frontend Engineer, DevOps Engineer, QA Engineer, Security Engineer, Technical Writer, Product Manager, **Codebase Analyst** (added via ADR-007/008). |
| `05-Skills` | Reusable engineering capabilities across Product, Architecture, Engineering, Quality, Security, Delivery, Documentation, and AI-Assisted Engineering. Includes the Codebase Analysis skill set (ADR-007/008). |
| `06-Prompts` | Reusable prompt assets. |
| `07-Templates` | Standard document templates and the full `09-Project Template` scaffold. |
| `08-Examples` | Reference implementations. |
| `09-Onboarding` | Framework documentation. |
| `10-Assets` | Branding, Diagrams (incl. `forgeos-explainer.png`), Icons. |
| `11-Collaboration Orchestration` | Context loading, standards loading, agent selection, decision-making, orchestration lifecycle, work-item management. |
| `12-Glossary` | Shared terminology and definitions. |

## Known Gaps (non-blocking)

The following are recorded in the documentation-gaps backlog and are **not** blockers for v1.0.0:

* `Framework/10-Assets/Branding/` and `Icons/` are empty (no brand/icon assets yet).
* `Framework/08-Examples/` has no worked reference implementation.
* External-issue-tracker synchronisation (ADR-005) is configured but no live tracker is bound for ForgeOS-the-framework.

These are candidates for a future **Minor** release.
