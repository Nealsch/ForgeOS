# Diagrams

This folder holds **diagrams belonging to the ForgeOS Project** — visual explainers of the project, its history and its decisions.

Diagrams here are supporting material, not engineering truth. If a diagram conflicts with project or Framework documentation, the document is authoritative and the diagram is corrected.

Framework-owned diagrams live in `Framework/10-Assets/Diagrams/`.
